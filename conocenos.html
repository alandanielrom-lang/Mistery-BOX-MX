Conoce el proyecto

Mystery Box MX es un proyecto académico desarrollado con el objetivo de combinar creatividad, emprendimiento y desarrollo tecnológico dentro de una propuesta interactiva enfocada en experiencias digitales.

El proyecto busca demostrar cómo el diseño web, la experiencia de usuario y las estrategias de sorpresa controlada pueden integrarse para construir una idea innovadora y funcional.

¿Qué es Mystery Box MX?

Mystery Box MX es una propuesta basada en el concepto de cajas sorpresa, donde el usuario adquiere una experiencia construida alrededor de la expectativa, el misterio y la emoción del descubrimiento.

La idea principal consiste en ofrecer diferentes categorías de cajas temáticas que contienen productos seleccionados previamente, manteniendo oculto el contenido exacto hasta el momento de apertura. Este enfoque busca generar una interacción diferente a la compra tradicional, transformando el proceso de adquisición en una experiencia más dinámica e inmersiva.

El proyecto integra elementos de diseño visual, identidad de marca, experiencia de usuario y programación web para desarrollar una plataforma moderna, funcional y atractiva. Además, incorpora conceptos relacionados con comportamiento del consumidor y percepción de valor, buscando entender cómo factores como la anticipación y la sorpresa pueden influir en la experiencia de compra.

Institución educativa

Espacio para fotografía del plantel

Este proyecto fue desarrollado por estudiantes del Colegio de Bachilleres del Estado de Veracruz Plantel 12, institución educativa enfocada en la formación académica y técnica de nivel medio superior.

El trabajo fue realizado dentro de la capacitación de Programación de Computadoras, específicamente en la materia de Emprendimiento, donde se busca que los estudiantes desarrollen propuestas innovadoras aplicando conocimientos tecnológicos, creatividad y pensamiento estratégico.

La finalidad de este proyecto es demostrar la capacidad de integrar programación, diseño web y desarrollo de ideas de negocio dentro de una plataforma funcional que combine tecnología y experiencia de usuario.

Objetivo del proyecto

El principal objetivo de Mystery Box MX es construir una experiencia digital innovadora que combine entretenimiento, interacción y comercio electrónico dentro de un mismo entorno.

A través de este proyecto buscamos aplicar conocimientos adquiridos en programación, diseño visual y emprendimiento para desarrollar una plataforma moderna con identidad propia. También buscamos comprender cómo el diseño y la experiencia de usuario pueden influir en la percepción de valor y en el interés del consumidor.

Además del aspecto técnico, el proyecto representa una oportunidad para desarrollar habilidades de trabajo en equipo, planeación, organización y resolución de problemas, elementos fundamentales dentro del desarrollo profesional y académico.
